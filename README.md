# SpendSense

## Technologies Used

1. Language → JavaScript
2. UI → shadcn/ui + Tailwind CSS
3. State → RTK (Redux ToolKit)
4. Charts → Recharts
5. Forms → RHF + Zod
6. Schema/Validation → Drizzle-Zod (auto) + Zod (manual)
7. Auth → Clerk
8. Database → Neon (PostgreSQL)
9. ORM → Drizzle ORM
10. Hosting → Vercel
